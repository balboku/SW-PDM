# ADR-005：完整 Vault 查詢與已驗證後端的畫面整合

2026-10-26。DEV-015 本輪契約；隔離實作與 QC 通過，僅本機隔離實作／驗證，不代表發版。
來源：使用者要求繼續完成剩餘任務；接續 DEV-012～014 已完成切片，基準 c12b852。

## 決策與相容性

- GET `/api/documents/search` 保留未指定 paged 的舊陣列（最多 50 筆）；`paged=true` 回傳 items、page、pageSize、totalCount、totalPages 及整個篩選結果的異常／出庫摘要。
  page 正整數、pageSize 1～100；固定 UpdatedAt 降序＋DocumentId 排序，超過最後頁自動定位最後頁；空結果為第 1/1 頁。
- 搜尋以參數化字面子字串比對目前文件識別及目前版本自訂屬性，不搜尋歷史版本；支援型別／出庫狀態與異常篩選。
  `%`／`_` 不當 wildcard，前端翻頁使用已套用條件，不混入尚未送出的輸入。
  失敗重試保留最後送出的條件，不退回上一組成功條件；舊陣列明示「已載入、非全部」，不能把 50 筆當總數。
- 品名優先文件層「品名」、再 PartName／Description；圖號只採文件層精確「圖號」。同欄多值不默默任選，顯示來源與衝突；組態屬性列在明細，不冒充文件層值。
- 新增唯讀 `/api/documents/{id}/integrity`，回傳目前版本的儲存屬性與 BOM 參照證據、未解析／歧義／新版參照及虛擬／抑制統計。
  缺目前版本與非虛擬未解析參照列為待處理；虛擬件不是缺檔，抑制件的未解析狀態不隱藏。舊版參照是需依設計基準確認的提醒，不一律稱錯誤。
- 清單與明細只使用資料庫快照，明示「未重新檢查實體 CAD／設計依賴」，不能把 0 筆資料庫異常稱為原生完整性已通過。
  不掃描或改寫現行 Vault，不呼叫 parser 修復，也不回填歷史 BOM；不暴露伺服器來源路徑。
- 沿用 ADR-003 的批次取得／預覽／復原 API，前端明確選擇「單份」或「這次出庫批次」。批次需本人 actor、指定 batchId、根文件一致且成功預覽才可送出；不得自動選第一批或依現行 BOM 猜批次。
  預覽列出可解除與排除項目；已還原／已入庫／他人／新鎖／版本改變者不動；保留微秒時間原字串。成功結果明列解除數與跳過項目，不假稱整批均已解除。
- 出庫預覽的真正目標只有根＋向下參照＋關聯工程圖；where-used 父文件只供查閱，不阻擋也不算入鎖定範圍。操作人名稱不是登入驗證，不新增 Auth。
  預覽必須回傳 documentId；既有鎖依文件身分查詢，不因父檔引用舊版而漏報鎖定。工程圖只列實際出庫範圍中的目前版本，歷史工程圖不納入。這是唯讀 DTO／預覽補正，不更改批次核心規則。
- 套件錯誤沿用 ADR-004 的穩定 code／issues 與人類可讀的下一步；只送真正改變的版本覆寫，下載成功不冒充 SolidWorks 幾何驗收。

## UX 意圖與安全矩陣

使用者先找圖、掃描風險，再查看明細；沿用表格／行動清單、右側 drawer 與確認 modal，不另做整頁重設計。
主畫面保留真實總數、篩選、頁碼、逐列缺失／新版提示。屬性來源、組態與完整參照放 drawer 的可發現明細；不常駐整頁教學。
使用思考習慣：#溝通設計、#可驗證性、#限制條件

| 模式 | 來源／目標／範圍 | 安全預設 | 主要 CTA／不能繼續時的下一步 |
|---|---|---|---|
| 查詢 | 目前文件與版本／篩選結果／分頁 | 唯讀、穩定排序、摘要涵蓋全部結果 | 篩選／翻頁；失敗重新載入，無結果清除條件 |
| 異常／屬性 | 目前版本快照／選取文件 | 不宣稱 CAD 已重驗；保留來源、未知與衝突 | 查看參照明細／來源；出庫人於 CAD 確認後入庫，不自動修復 |
| 單份取消 | 操作人／選取文件／1 份 | 原鎖人、時間、版本皆相符 | 預覽後確認解除；競爭失敗重新檢查 |
| 批次復原 | 操作人／明確批次／該次新鎖 | 不自動選批次、不解除排除項、不推導舊批次 | 載入批次、預覽、確認解除 N 份；無批次改用單份 |
| 套件 | 所選版本／ZIP／完整依賴 | 失敗不出不完整 ZIP | 調整選版／重設後重試；錯誤細節列安全檔名及 code |

## QA、停止條件與範圍外

- 真實產品 HTTP＋SQLite／全新 55433 PostgreSQL：超過 50 筆、完整掃頁不重漏、同時間穩定排序、整體摘要、條件重設／超頁、Unicode／特殊字元、屬性來源／衝突、歷史資料排除、虛擬／抑制／歧義／舊版與缺目前版本，前後資料／BOM／鎖不變。
- UI fixture 不再用搜尋替身；使用真實產品查詢與批次服務，只有故障注入留在 fixture。測試對象限定 5010／5175 與私有 SQLite／Vault；舊 112 項 HTTP、13 項前端邏輯回歸。
- 實際瀏覽器 1440×900、1024×768、768×1024、390×844：分頁、搜尋、異常明細、屬性、單份／批次預覽與排除／競爭／錯誤恢復、套件阻擋、長檔名。每狀態記錄 CTA、資料數、可見錯誤、viewport／截圖與 overflow；正常畫面非預期錯誤即失敗。
- 不執行 migration，不改 entity、模型、入庫／parser、批次後端規則、目前 5432/swpdm、服務 5000／5174 或 Vault 原檔；不整包採用原 dirty 後端。
- 需 live 資料寫入、schema、放寬安全保護、未完成依賴或原工作區重疊時停止；有測試／畫面缺口則不標通過。
- 本輪不 commit／push／merge／部署。後續批次發版需使用者明確要求；原生完整幾何重建、第二台工作站、Auth 與歷史資料修復仍屬另行恢復條件，不因這輪整合宣稱完成。

本 ADR 相容擴充既有搜尋，刻意取代前端「固定前 50 筆」及「只支援單份取消」的舊限制；ADR-003／004 仍為鎖與套件核心權威。
